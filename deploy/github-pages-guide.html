Deploy Your Website to GitHub Pages

Follow these 6 steps. Total time: ~5 minutes. No coding required.

📁 Files You'll Upload

Your deploy folder contains these files — select all of them when dragging:

  • index.html — Your complete website (all styling is built in)
  • .nojekyll — Tells GitHub to skip Jekyll processing (keeps everything working)
1

Go to github.com and create a new repository

Sign in to github.com/new and fill in:

Repository name: chloe-portfolio (or any name you like)
Visibility: Public (required for free GitHub Pages)
Don't add a README or .gitignore — leave it empty

Click "Create repository" at the bottom.

↓
2

Drag your files into the repository

On the empty repository page, you'll see a big dashed area that says "dragging files here to add them to your repository." Open your deploy folder, select both files, and drag them onto the page.

📁 your-username / chloe-portfolio
💾
Drag files here to add them to your repository
Drop index.html and .nojekyll here

After dropping, type a commit message like Add portfolio website and click "Commit changes".

↓
3

Go to repository Settings → Pages

Click the Settings tab at the top of your repository, then find Pages in the left sidebar.

4

Set Source to "Deploy from a branch"

Under Build and deployment, make sure Source is set to Deploy from a branch.

Then set the branch to main and folder to / (root).

Click Save.

↓
5

Wait ~1-2 minutes for the build

GitHub will build your site. Refresh the Pages settings page after a minute — you'll see a green success message with your live URL.

↓
6

Visit your live website!

Your website is now live. The URL will look like this:

🎉 Your site is live!

https://your-username.github.io/chloe-portfolio/

Replace your-username with your actual GitHub username and chloe-portfolio with your repo name.

💡 Quick Tips

Can't see .nojekyll? — Files starting with a dot are hidden on some systems. In File Explorer, turn on "Show hidden files" (View → Hidden items). If you can't drag it, don't worry — your site will still work; .nojekyll is just a safety net.

Want to update later? — Just drag a new index.html into the same repo and commit. GitHub auto-rebuilds in seconds.

Custom domain? — In Pages settings, you can add a custom domain (e.g. chloechan.com) under the "Custom domain" field.
